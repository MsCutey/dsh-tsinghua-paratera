# 1.0.0 发布前安全审查摘要

范围包括插件源码、原生助手、安装/后台任务、网络与浏览器边界、实际发布归档、依赖及拟公开 Git 元数据。
这是一轮工程审查和回归验证，不是独立第三方渗透测试或“零漏洞”认证。

## 修复

1. 敏感操作增加固定域名、浏览器 frame 与隔离执行上下文校验，避免跳转到其他来源时提交密码/验证码。
2. 调试连接限制为发现端口的回环 WebSocket，禁止发现请求跟随重定向。
3. 状态/API/导入响应按白名单输出；余额不再持久化/展示无关院系、班级和用户标识；不回传任意上游字段。
4. 密钥指纹改为哈希摘要；密码状态检查不解密；未知异常映射为固定错误码。
5. 后台任务、保存密码和长期浏览器信任使用明确的用户选择；二次认证等待设置超时。
6. 自定义 home 隔离专用 profile、原生凭据与任务标识；仅使用随插件分发的原生脚本。
7. 公开版本通过允许列表导出，使用新建的中性署名历史，不迁移内部开发历史；发布前扫描内容和归档元数据。

## 验证方式

- 普通回归测试及隐私边界测试。
- 安装包 SDK 和完整浏览器 React/插槽测试，使用虚构数据。
- 临时 Chrome 验证隔离执行上下文不会触发页面篡改的 JavaScript 全局函数，拒绝不同来源。
- 本地 gitleaks 密钥扫描及个人标识定向扫描；依赖公告审计。
- 正式包解压后的文件列表、源码内容和公开提交作者/提交者元数据检查。

## 残余风险

本机 token 缓存不是硬件隔离，Chrome CDP 与宿主凭据服务依赖可信的 OS 用户环境；同用户恶意程序、其他恶意插件、平台或浏览器自身的安全事件仍可能造成泄露。
未验证的硬件、宿主版本、Windows 实机流程与长期无人值守续期，应按 README 的测试矩阵在目标环境验收。
