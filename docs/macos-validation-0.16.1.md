## macos.2 输入栏标记修复

用户截图与本机模型菜单确认：当前选中模型属于 Paratera，但输入栏没有余额标记。
复现发现，客户端在模型服务尚未激活时会把组件永久绑定到空 store，后续切换 Paratera 模型也不能恢复。
修复为使用独立的 `ctx.inject(['modelDirectories'], ...)`，等待服务就绪后注册余额组件，保留设置页的独立注册和降级能力。

新增前端延迟服务回归，并在本机真实 Cordis 上下文验证：模型服务未出现时设置页可用，模型服务出现后余额组件绑定到正确的会话 store。
完整回归 244 项，242 通过，2 项安装包 SDK 测试单独执行并通过。实际 Desktop 显示由用户重启后核对，不以隔离测试替代。

## 功能与适配

保留上游新增的控制台认证、API 密钥管理、模型导入及即时更新、模型推荐值和思考挡位、二次认证、客户端/宿主兼容性诊断。

- Mac 原生凭据窗口能报告打开、保存、取消和失败；已有凭据时仍等待窗口关闭后再登录，取消不会误用旧凭据报告新保存成功。
- 钥匙串状态查询只匹配条目是否存在，不请求密码数据；密码仍仅在宿主实际执行登录时读取。
- 安装器将所选 `DSH_HOME` 传给后台任务；自定义 home 使用独立 LaunchAgent 名称。注册失败不会报告全部成功；Mac 卸载先停止任务。
- 无人值守续期遇到二次认证时清理本次挂起的浏览器，让用户回到 Desktop 设置页继续。
- 单元测试、临时安装和隔离宿主显式使用 `--no-task`；真实 launchd 验证使用独立名称和只写标记的脚本。
